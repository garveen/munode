# MuNode 性能优化方案

## 1. 语音路由系统优化

### 1.1 当前状态分析

`VoiceRouter`（edge-server/src/voice/voice-router.ts）已经实现了事件驱动的缓存机制，但仍有优化空间。

#### 当前实现优点
- 使用 `routingCache` 缓存路由结果
- `serializedPacketCache` 避免重复序列化
- 事件驱动的缓存重建（`rebuildChannelCache`、`rebuildWhisperCache`）

#### 可优化点

**1.1.1 序列化缓存优化**

当前实现在发送语音包时会检查缓存大小并删除旧条目：

```typescript
// 当前实现（voice-router.ts:566-570）
if (this.serializedPacketCache.size > 1000) {
  const firstKey = this.serializedPacketCache.keys().next().value;
  this.serializedPacketCache.delete(firstKey);
}
```

**建议改进**：使用 LRU 缓存替代简单的 FIFO 删除

```typescript
// 推荐方案：使用 lru-cache 库
import { LRUCache } from 'lru-cache';

private serializedPacketCache = new LRUCache<string, Buffer>({
  max: 500,
  ttl: 1000, // 1秒TTL，语音包时效性很强
  updateAgeOnGet: false,
});
```

**预期收益**：
- 减少缓存未命中率
- 自动过期机制避免内存泄漏
- 更符合语音包访问模式

### 1.2 频道索引优化

**建议增强**：添加更多索引支持复杂查询

## 2. OCB2-AES128 加密性能优化

语音加密是系统的性能关键路径，每秒可能处理 1000+ 个语音包。当前 `ocb2-aes128.ts` 实现有以下优化机会：

### 2.1 当前实现分析

```typescript
// 当前实现中每次加密/解密都创建新的 cipher 实例
const cipher = createCipheriv('aes-128-ecb', this.key, Buffer.alloc(0)).setAutoPadding(false);
// 解密时创建两个
const encrypt = createCipheriv('aes-128-ecb', this.key, Buffer.alloc(0)).setAutoPadding(false);
const decrypt = createDecipheriv('aes-128-ecb', this.key, Buffer.alloc(0)).setAutoPadding(false);
```

**问题**：
- 每次加解密都创建新的 Cipher 对象
- 频繁的 Buffer.alloc 调用
- 循环中的对象分配

### 2.2 建议优化方案

**2.2.1 复用 Cipher 实例**

```typescript
export class OCB2AES128 {
  // 缓存 cipher 实例
  private encryptCipher?: ReturnType<typeof createCipheriv>;
  private decryptCipherEnc?: ReturnType<typeof createCipheriv>;
  private decryptCipherDec?: ReturnType<typeof createDecipheriv>;
  
  // 预分配常用 Buffer
  private static readonly ZERO_IV = Buffer.alloc(0);
  private readonly tmpBlock = Buffer.alloc(16);
  private readonly checksumBlock = Buffer.alloc(16);
  
  setKey(key: Buffer, encryptIV: Buffer, decryptIV: Buffer): void {
    // ...原有验证逻辑...
    
    // 创建并缓存 cipher 实例
    this.encryptCipher = createCipheriv('aes-128-ecb', this.key!, OCB2AES128.ZERO_IV)
      .setAutoPadding(false);
    this.decryptCipherEnc = createCipheriv('aes-128-ecb', this.key!, OCB2AES128.ZERO_IV)
      .setAutoPadding(false);
    this.decryptCipherDec = createDecipheriv('aes-128-ecb', this.key!, OCB2AES128.ZERO_IV)
      .setAutoPadding(false);
  }
  
  encrypt(plainText: Buffer): Buffer {
    if (!this.ready() || !this.encryptCipher) {
      throw new Error('Crypto not initialized');
    }
    
    // 复用 cipher 实例
    const aesEncrypt = (data: Buffer) => this.encryptCipher!.update(data);
    
    // ...其余逻辑不变...
  }
}
```

**2.2.2 预分配工作 Buffer**

```typescript
export class OCB2AES128 {
  // 预分配工作 Buffer，避免每次加解密时分配
  private readonly workBuffer = {
    checksum: Buffer.alloc(16),
    tmp: Buffer.alloc(16),
    delta: Buffer.alloc(16),
    saveiv: Buffer.alloc(16),
  };
  
  private ocbEncrypt(
    plainText: Buffer,
    cipherText: Buffer,
    nonce: Buffer,
    aesEncrypt: (data: Buffer) => Buffer
  ): Buffer {
    // 复用预分配的 Buffer
    const { checksum, tmp } = this.workBuffer;
    
    // 使用 fill 而不是创建新 Buffer
    checksum.fill(0);
    tmp.fill(0);
    
    // ...其余逻辑不变，但使用预分配的 Buffer...
  }
}
```

**2.2.3 优化 XOR 操作**

```typescript
// 当前：逐字节 XOR
private xor(dst: Buffer, a: Buffer, b: Buffer): void {
  for (let i = 0; i < OCB2AES128.BLOCK_SIZE; i++) {
    dst[i] = a[i] ^ b[i];
  }
}

// 优化：使用 BigInt 或 TypedArray 进行批量 XOR
private xorOptimized(dst: Buffer, a: Buffer, b: Buffer): void {
  // 使用 DataView 进行 8 字节批量操作
  const dstView = new DataView(dst.buffer, dst.byteOffset);
  const aView = new DataView(a.buffer, a.byteOffset);
  const bView = new DataView(b.buffer, b.byteOffset);
  
  // 16 字节 = 2 个 BigUint64
  dstView.setBigUint64(0, aView.getBigUint64(0) ^ bView.getBigUint64(0));
  dstView.setBigUint64(8, aView.getBigUint64(8) ^ bView.getBigUint64(8));
}
```

### 2.3 性能预期

| 优化项 | 预期提升 | 说明 |
|--------|----------|------|
| Cipher 实例复用 | 30-50% | 避免频繁创建 Cipher 对象 |
| Buffer 预分配 | 10-20% | 减少 GC 压力 |
| XOR 批量操作 | 5-10% | 减少循环开销 |
| **总体** | **40-70%** | 组合效果 |

## 3. RPC 通信优化

### 3.1 RPC 压缩

对于大型消息（如 fullSync），启用压缩可显著减少传输量。

```typescript
// 建议在 PacketCodec 中添加压缩支持
import { gzip, gunzip } from 'zlib';
import { promisify } from 'util';

const gzipAsync = promisify(gzip);
const gunzipAsync = promisify(gunzip);

const COMPRESSION_THRESHOLD = 2048; // 超过2KB启用压缩

async encode(packet: EdgeHubPacket): Promise<Buffer> {
  const data = packet.serialize();
  if (data.length > COMPRESSION_THRESHOLD) {
    const compressed = await gzipAsync(data);
    // 添加压缩标识头
    return Buffer.concat([Buffer.from([0x01]), compressed]);
  }
  return Buffer.concat([Buffer.from([0x00]), data]);
}

async decode(data: Buffer): Promise<EdgeHubPacket> {
  const isCompressed = data[0] === 0x01;
  const payload = data.slice(1);
  
  if (isCompressed) {
    const decompressed = await gunzipAsync(payload);
    return EdgeHubPacket.deserialize(decompressed);
  }
  return EdgeHubPacket.deserialize(payload);
}
```

**预期收益**：
- fullSync 等大消息传输量减少 60-80%
- 降低网络带宽占用
- 对小消息无额外开销

## 4. 数据库优化

### 4.1 查询优化

**4.1.1 频道层级查询**

`getChannelHierarchy` 当前使用循环查询：

```typescript
// 当前实现（database.ts:1350-1372）
async getChannelHierarchy(channel_id: number): Promise<number[]> {
  const hierarchy: number[] = [];
  let currentId = channel_id;
  while (currentId !== -1 && currentId !== null) {
    hierarchy.unshift(currentId);
    if (currentId === 0) break;
    const stmt = await this.db.prepare('SELECT parent_id FROM channels WHERE id = ?');
    const row = await stmt.get(currentId);
    // ...
  }
  return hierarchy;
}
```

**建议改进**：使用 CTE 递归查询

项目使用 `sqlite3@^5.1.7`，底层 SQLite 版本支持 CTE（3.8.3+），可以直接使用：

```typescript
async getChannelHierarchy(channel_id: number): Promise<number[]> {
  const query = `
    WITH RECURSIVE channel_hierarchy AS (
      SELECT id, parent_id, 0 as depth
      FROM channels
      WHERE id = ?
      UNION ALL
      SELECT c.id, c.parent_id, ch.depth + 1
      FROM channels c
      JOIN channel_hierarchy ch ON c.id = ch.parent_id
      WHERE ch.parent_id > 0
    )
    SELECT id FROM channel_hierarchy ORDER BY depth DESC
  `;
  
  const stmt = await this.db.prepare(query);
  const rows = await stmt.all(channel_id);
  return rows.map(row => row.id);
}
```

**预期收益**：
- 将 N 次查询减少为 1 次（N = 频道深度）
- 减少数据库连接开销
- 对于深层频道树效果更明显

## 6. 广播事件优化

### 6.1 Hub 对 Edge 广播

所有 Hub 对 Edge 的广播事件都应使用 `Promise.allSettled`，避免单个 Edge 失败影响其他 Edge：

```typescript
// 推荐实现
async broadcastToEdges(method: string, params: any, excludeEdgeId?: number) {
  const promises = Array.from(this.edgeChannels.entries())
    .filter(([edgeId]) => edgeId !== excludeEdgeId)
    .map(([edgeId, channel]) =>
      channel.notify(method, params)
        .catch(err => {
          this.logger.error(`Broadcast to Edge ${edgeId} failed:`, err);
          return null;
        })
    );
  
  await Promise.allSettled(promises);
}
```

### 6.2 Edge 对 Client 广播

Edge 向客户端广播时同样应使用 `Promise.allSettled`：

```typescript
// Edge 广播到所有客户端
async broadcastToClients(
  message: Buffer,
  excludeSession?: number
) {
  const promises = Array.from(this.clients.values())
    .filter(client => client.session !== excludeSession)
    .map(client =>
      client.send(message)
        .catch(err => {
          this.logger.error(`Send to client ${client.session} failed:`, err);
          return null;
        })
    );
  
  await Promise.allSettled(promises);
}
```

**优点**：
- 单个接收者失败不影响其他接收者
- 所有发送并行执行
- 自动收集所有结果（包括失败）

## 8. 基准测试建议

### 8.1 OCB2 加密性能测试

```typescript
// OCB2 加密性能测试
async benchmarkOCB2(iterations: number = 10000) {
  const ocb = new OCB2AES128();
  ocb.generateKey();
  
  const testData = Buffer.alloc(480); // 典型语音包大小
  randomBytes(480).copy(testData);
  
  const encryptTimes: number[] = [];
  const decryptTimes: number[] = [];
  
  for (let i = 0; i < iterations; i++) {
    // 加密
    const encStart = process.hrtime.bigint();
    const encrypted = ocb.encrypt(testData);
    const encEnd = process.hrtime.bigint();
    encryptTimes.push(Number(encEnd - encStart) / 1000); // 微秒
    
    // 解密
    const decStart = process.hrtime.bigint();
    ocb.decrypt(encrypted);
    const decEnd = process.hrtime.bigint();
    decryptTimes.push(Number(decEnd - decStart) / 1000);
  }
  
  return {
    encryptAvgUs: avg(encryptTimes),
    encryptP99Us: percentile(encryptTimes, 0.99),
    decryptAvgUs: avg(decryptTimes),
    decryptP99Us: percentile(decryptTimes, 0.99),
  };
}
```
